# todo.sh

A read-only todo list reader in pure bash. It exists so evergif has a
realistic shell-script project to record.

<!-- evergif:start -->
![Terminal demo: todo.sh --help lists the list and stats commands, todo.sh list --open shows three open tasks, and todo.sh stats counts 2 done and 3 open](demo/evergif.gif)
<!-- evergif:end -->

## Usage

```bash
./todo.sh list
./todo.sh list --open
./todo.sh stats
```
